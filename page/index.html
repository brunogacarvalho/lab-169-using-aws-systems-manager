AWS CLOUD LABS

Usando o AWS Systems Manager

Lab 169 - Administração e gerenciamento de instâncias EC2

Neste laboratório, explorei recursos do AWS Systems Manager para administrar uma instância EC2, executar comandos remotamente, armazenar parâmetros e acessar o terminal sem utilizar SSH.

AWS Systems Manager Amazon EC2 Cloud Management
PRÁTICA

O que foi realizado

As principais atividades desenvolvidas durante o laboratório.

01

Fleet Manager - Inventory

Criação de uma associação de inventário e consulta das informações coletadas sobre a instância gerenciada, incluindo os aplicativos instalados.

Inventário
02

Run Command

Execução remota do documento Install Dashboard App, instalação dos componentes da aplicação e verificação do resultado da execução.

Execução remota
03

Parameter Store

Criação de um parâmetro do tipo String para habilitar um recurso beta do Dashboard, exibindo um terceiro gráfico.

Gerenciamento de parâmetros
04

Session Manager

Acesso ao terminal da instância EC2, execução de comandos Linux e consultas utilizando a AWS CLI, sem conexão SSH.

Acesso remoto
